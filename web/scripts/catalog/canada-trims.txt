# Canadian trim names for the vehicle pages (migration 0097). Compiled by CarmaCars from the makers' Canadian lineups:
# trim names are facts, so the list is ours to publish. One line per model and run of model years, entry trim first:
#   make | model | first year-last year | Trim, Trim, Trim
# A model year may have more than one line (a separate hybrid or performance line): the trims are added in order.
# Names in a trim that EPA uses for a powertrain (Hybrid, Prime, GLI, Si, Type R, N, AMG C 43, Long Range, M340i...) tie
# the trim to that powertrain; AWD, xDrive, 4MATIC, quattro tie it to all-wheel drive. Admins can correct or add lines
# in Admin > Settings > Vehicle pages; those edits are kept by every import.
