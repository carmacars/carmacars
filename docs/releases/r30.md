## Staff tools

- Recorded interviews for remote assistant roles now capture each answer on video, with a camera and microphone check first
- Each answer has a set time with a visible countdown; recording stops by itself when the time is up
- Hiring can set the answer time, the retakes allowed and how long interview videos are kept (90 days by default)
- Each answer's video plays beside its transcript and score, and all answers can be watched in one go
