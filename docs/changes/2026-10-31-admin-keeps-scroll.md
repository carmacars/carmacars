# Admin keeps your place on the page

Switching a tab or a filter on an Admin page (a booking's Money, Review or Changes tab, the hiring days, any filter row),
or pressing a button whose result opens another tab of the same page, no longer jumps back to the top: the page stays
where you were. Going to a different page still starts at the top.

## Guides

No guide change: nothing to do differently; the page simply stays where it was.
