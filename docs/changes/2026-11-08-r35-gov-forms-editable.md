# Government forms as editable as the rental agreements (Release 35, part S: 0870, 0872)

Branch `r35-s`. Migrations `0870_r35s_gov_forms_editable.sql` (the door, wrapped as `door_pre0870`) and
`0872_r35s_gov_forms_guides.sql` (generated by `supabase/seed/0872_gen_guides.mjs`). No applied migration is edited. Tests:
`supabase/tests/99_r35s_gov_forms_editable.sql`, `web/src/features/official-forms/edit.test.ts`,
`web/tests/e2e/gov-forms-editable.spec.ts`.

The owner: "Make sure the government forms are as editable as the rental agreements", with the rule of November 8, 2026: the
forms are the exact official ServiceOntario PDFs with only their boxes filled. Editing means the filled-in values and the
mapping (which platform value goes in which box), never the form's own text or layout.

| Item | What changed |
| --- | --- |
| 1. A value changed on one form | On a form's page (`/admin/government-forms/<id>`, `/staff/government-forms/<id>`), **Values on this form** lists the text boxes of the official form (or the rows of its data sheet while the form is not in use as a PDF), each with its value, and for a value changed by hand the value from the records. **Change a value**: choose the box, type the value (at most the box's length), give a reason, **Save as a new version** (`app.government_form_edit`, door `government_form_edit`). The change is kept in `government_form_overrides` and goes into every later version of that car's form; the form is made again as version N+1 (`government_form_fills.overrides` says which changes a version carries); audited (`government_form_edit`, with the value before, the box and the reason). **Back to the records** ends a change with a reason (`government_form_restore`). A checkbox, choice or signature box is not filled (done by hand at the counter); a form signed in ink or filed is never changed; an earlier version is read only |
| 2. Versions | **Versions** on the form's page lists every version (status, date, by whom, the values changed by hand), each with its page and its data sheet; staff and an Admin open any of them. The Government forms box shows each form's version and how many values were changed |
| 3. The mapping per form | Admin **Settings > Forms** and, for fleet, **Owners > Government forms** (`/staff/government-forms`): **Preview with** a sample car (made-up values, `app.registry_sample_context`, example.test) or a real car fills the official PDF with the mapping on screen, saved or not (`form_template_preview` takes `field_map`). Saving takes a note; every save is kept in `pdf_template_map_history` (trigger on `pdf_templates`) and audited (`form_template_map`); **Earlier mappings** lists them with **Load**. Fleet maps and previews; only an Admin uploads a form (`can_upload`) |
| 4. Make again keeps the changes | `app.government_forms_make_again` keeps the values changed by hand; **Discard the values changed by hand** ends them first (forms signed or filed keep theirs). An Admin or fleet (customer service reads). The message says how many were kept or discarded |
| 5. Fleet has the same access | `app.government_forms_editor`: an Admin or fleet changes values, makes the forms again and maps them (the standing rule: an Admin upgrade goes to the staff role that handles it). Customer service keeps read access; finance and owners have none |
| 6. Owners see the final version | The owner's Documents and official form read the current version only (unchanged reads, now tested); a corrected form replaces the earlier one there |
| 7. Only the publisher's PDF is filled | `app.official_form_is_publisher`: a form is given as the official PDF only when its template is the publisher's download byte for byte (`official_form_originals.sha256`, stored by the forms-fetch workflow) or an Admin's upload of the official PDF, and never a laid-out copy (`overlay`). Otherwise the owner gets the data sheet (a list of values, not a look-alike). Settings shows "Not the publisher's PDF: data sheet in use" for such a template. Forms in use that failed the check were made again once |

## The forms and how each is filled

| Form | How it is filled |
| --- | --- |
| SR-LV-006 Application for Vehicle Registration | The publisher's fillable PDF (AcroForm), only its empty text boxes filled, as an incremental update after the publisher's last byte (`pdf-update.ts`); checkboxes and signatures by hand |
| SR-LV-012 Supplementary Application | The same (AcroForm, text boxes only) |
| 013-0169 Addendum to Sworn Statement (tax-exempt transfer between corporations) | The same (AcroForm, text boxes only) |
| 013-1155 Sworn Statement for the Transfer of a Used Motor Vehicle | The same (AcroForm, text boxes only); sworn in person |
| ON00453 Proof of Business Address (RIN) | An Adobe dynamic (XFA) form: the publisher's download with its XFA data boxes filled, once the forms-fetch workflow stored it. The 0047 laid-out copy (a look-alike) was retired in 0122 and is now refused by the check above: owners get the data sheet |

The 0047 templates of the four fillable forms were the publisher's PDFs decrypted and saved again (qpdf, XFA part removed);
0122 registered each publisher's download and `app.official_templates_use_originals` (forms-fetch, last run on main on
2026-10-24) makes it the template. Any template still on such a copy now gives the data sheet until the download is used.

## Guides

- `admin/owners-and-onboarding`: Change a value, Versions, Back to the records, Make again keeping or discarding the changes.
- `admin/settings`: the preview on the sample car with the mapping on screen, the note and Earlier mappings, fleet's part, the publisher's PDF only.
- `va/fleet`: Government forms (release 35).
- `owner/documents-and-forms`: a corrected form replaces the earlier one in Documents.
