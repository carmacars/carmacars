## 1. Staff Welcome: what the agreement waits for

| Item | What changed |
| --- | --- |
| The message | On the agreement step, while the agreement is not made yet: "Complete your profile to get your agreement: missing home address and driver's licence number", each with a link to the place that fills it (the profile page for the home address, the licence box on the same page). A value only an Admin can set (start date, pay, vehicle types) reads "Waiting for CarmaCars to set your start date" |
| How soon | "Your agreement arrives here within about 5 minutes": the Worker's agreements job runs on the five-minute tick when the database says one is due (`custom-worker.ts`, `server_jobs_due`) |
| Made true | Until now only saving the licence number cleared the waiting row (`staff_agreement_auto`, kept a day after a try), so a home address, a start date or a pay set later waited up to a day. Migration 2470: a change to the home address, start date or licence number of a staff profile, or to the start date or pay of their hire, clears a waiting row, so the next five-minute run makes the agreement |
| Privacy | Only the names of the missing values are read; a licence number is never shown |

## 2. Every form: a summary, a marked field, the focus

One mechanism on the document (`web/src/lib/forms/guard-dom.ts`, mounted once in the root layout by `components/FormGuard.tsx`), so it covers
all forms of the site without editing them. On a form that cannot be sent it shows (a) a summary near the submit button listing each
missing or wrong field (a link to it), (b) the field with `aria-invalid`, a red outline and a short message under it, (c) the page
scrolled to the first one with the focus in it. It uses three sources: the browser's own check (required, type, pattern, length, range;
a form with `noValidate` is checked before its own handler, a visible failing field stops it), the fields a form marks `aria-invalid` itself
(the wizards, the contact and apply forms, Act and SaveForm: listed and focused, their own message kept), and a server error shown as an
alert, which marks the field whose label the message names. A form opts out with `data-form-guard="off"`.
