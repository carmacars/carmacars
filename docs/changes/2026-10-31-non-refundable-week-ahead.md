# The non-refundable discount only when booked a week or more before pickup (0241)

The non-refundable booking (10% off the rental charge, no refund) can be chosen only when the booking is made at least
7 days before pickup. On the request form the choice is greyed out for sooner pickups, with the reason; a choice made
before the dates changed counts as standard. The database refuses a request or offer that would break the rule, so staff
offers follow it too. Rentals already confirmed or under way are not affected. The number of days is a Program setting
(non-refundable minimum days; 0 turns the rule off).

## Guides

No guide change: the request form and the "i" beside the cancellation rules explain it where the choice is made.
