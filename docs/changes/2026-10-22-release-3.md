## Saved as you type

Every form contact capture covers shows one short, muted line under it: "Saved as you type so you can pick up where
you left off." with a link to the privacy policy. The forms: the booking request (the driver step), the contact form,
List your car, the owner application, Create an account, the discount game claim and the live chat's details. The live
chat's details form now also saves as it is typed (form `chat`), so the line is true there too.

it: the audit log shows "Hide sample cars" pressed twice on October 21 (18:19 and 21:49 UTC) from the Admin account,
each time minutes after a car was added; no migration, job or rule unpublishes a sample car (0065 to 0093 checked,
0074 changes titles only). Migration 0094 publishes every sample car again (app.sample_cars_restore_0094, which runs

site?" with Hide them and Keep them before anything is hidden, so only an Admin who confirms can hide them. DB test
65_release_3_sample_cars.sql.

The two other sample vehicles live without a listing are not catalogue cars: two "2022 Toyota Corolla Test" cars in

named "Test" with no price; delete them in Admin > Cars if they were tests.
