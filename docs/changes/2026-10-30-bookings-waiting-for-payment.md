# Bookings waiting for payment in the bookings list

- Admin > Bookings lists the bookings waiting for payment (the renter accepted the offer and has not paid yet) first,
  with a "Waiting for payment" badge ("Waiting for signature and payment" when not signed either), a line saying how
  many there are, and a "Waiting for payment" filter with its count.
- Requests (Admin and staff): the state reads "waiting for payment". The staff Requests page has the filter and a
  "Waiting for payment" count too (it had none).

## Guides
No guide change: the screens' steps are unchanged, only the labels and the order of the list.
