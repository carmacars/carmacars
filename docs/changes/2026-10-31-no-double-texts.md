# A booking message is texted once, not twice (0270)

Renters get booking messages by text by default, and while emails were held for the daily limit the held email was
also texted, so the same message (an offer, a request received) reached the renter twice. Now the held email is not
texted when that booking's message already went by text, and two texts with the same words to the same number within
10 minutes are sent once (the second shows as skipped in Texts and calls).

## Guides

No guide change: nothing to do differently; renters simply get one text.
