# The investor video: storyboard

The scene by scene plan of the narrated deck (November 1, 2026), made from the script (`script.md`) and the deck as it
renders with the sample figures (`web/scripts/investor-video/figures.sample.json`). Times are estimated from the word
count; the real run times each scene to its voice. The words are the script's, filled with the deck's own numbers when
the video is made.

Every scene shows the deck's own slides, animated by the frame clock: the pieces rise in, numbers count up, bars grow and
the screens drift. A scene opens with a fade, slide or zoom; inside a feature group the slides push in one after another
with a soft whoosh. The voice is spoken over a quiet pad, and the captions are the script's words.

Total: about 4:20 (30 scenes, 92 slides). How to make the video: the last section.

## Making the video

The video is made by `.github/workflows/investor-video.yml`. It reads the live deck figures (read only), renders 1080p
and 720p on GitHub's runners (not on the shared build machine), checks the result and uploads it to the private bucket
`investor-media/deck-video`, where the deck page shows it to signed-in investors.

- After this change is merged to main and deployed: `gh workflow run investor-video.yml -R carmacars/carmacars --ref main -f upload=true -f checks=true`.
- To render and check without replacing the published video, run the same command with `-f upload=false`. The MP4s, the poster and a contact sheet stay as the run's artifact `investor-video` for 3 days.
- The workflow also runs by itself on the 1st of each month, so the dates and figures follow the deck.
- To build only the plan locally (no render): `cd web && node scripts/investor-video/build.mjs --out .video && node scripts/investor-video/timeline.mjs --dir .video --estimate`.
